# 📊 Student Performance Prediction System

A Machine Learning-based web application that predicts whether a student will **Pass or Fail** based on key academic factors such as study hours, attendance, and previous marks. The system helps in identifying at-risk students early and enables data-driven academic decisions.

---

# 🚀 Features

* 🎯 Predict student performance (Pass/Fail)
* 📈 Uses Machine Learning (Logistic Regression)
* 🌐 Interactive web interface using Flask
* 🎨 Modern UI with smooth animations and responsive design
* ⚡ Instant prediction with confidence score
* 🔄 Clean UX with landing page + prediction flow

---

# 🧠 Technologies Used

* **Python**
* **Pandas, NumPy** – Data processing
* **Scikit-learn** – Machine Learning model
* **Flask** – Backend web framework
* **HTML, CSS** – Frontend UI

---

# 📂 Dataset Features

* Study Hours (per day)
* Attendance (%)
* Previous Marks
* Final Result (Pass/Fail)

---

# ⚙️ How It Works

1. User enters student details
2. Data is processed and passed to the trained ML model
3. Model predicts the outcome (Pass/Fail)
4. Result is displayed with a confidence score
